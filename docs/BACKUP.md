# Резервное копирование

Google Таблица **не** бэкап: она обновляется из БД и может быть перезаписана.

1. **Neon:** включите восстановление на момент времени (PITR) и запомните окно хранения тарифа. Регулярно тренируйте восстановление в отдельную ветку.
2. **Логические дампы:** `DIRECT_URL=... ./scripts/backup.sh ./backups` (нужен `pg_dump` версии не ниже сервера). Запускайте по расписанию **на своём сервере**, а не в публичных CI: дамп содержит персональные данные. Храните копии зашифрованными, ограничьте доступ.
3. **Проверка:** раз в квартал восстановите дамп в чистую базу (`pg_restore --no-owner -d <база> файл.dump`), выполните `npx prisma migrate deploy`, откройте панель.
4. **Не забудьте:** список переменных окружения (в менеджере паролей), сертификат Минцифры, JSON-ключ сервисного аккаунта Google — их нет в БД.
5. **Удаление по запросу** должно доходить и до копий: учитывайте срок хранения бэкапов в политике конфиденциальности.
