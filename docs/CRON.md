# Периодические задачи (cron)

| Задача | Адрес | Как часто | Что делает |
|---|---|---|---|
| **tick** | `GET /api/cron/tick` | каждые 5 минут | напоминания за 24 ч и за 2 ч, уведомления об отмене, синхронизация с Google Таблицей (шаги независимы) |
| cleanup | `GET /api/cron/cleanup` | раз в сутки | удаляет просроченные сессии диалогов, старые события вебхука и выполненные задачи синхронизации |

Каждый адрес защищён: заголовок `Authorization: Bearer <CRON_SECRET>`, иначе `401`.
Адреса `/api/cron/reminders` и `/api/cron/sync-google` остаются и делают то же, что соответствующие половины `tick`.

## Вариант A. Тариф Hobby: внешний бесплатный планировщик

Vercel Hobby разрешает cron только раз в сутки, поэтому `vercel.json` содержит одну ежедневную задачу (cleanup),
а `tick` вызывается снаружи. Подойдёт любой сервис, умеющий делать HTTP GET по расписанию с заголовком, например **cron-job.org**:

1. Зарегистрируйтесь и создайте задачу (Create cronjob).
2. URL: `https://ВАШ-ДОМЕН.vercel.app/api/cron/tick`, метод **GET**.
3. Расписание: **каждые 5 минут**.
4. В расширенных настройках добавьте заголовок `Authorization` со значением `Bearer <ваш CRON_SECRET>`.
5. Включите уведомление о неудачных запусках (ответ `500`/`401` означает сбой).
6. Нажмите «Test run»: в ответе должно быть `{"ok":true,...}`.

Названия полей в интерфейсе сервиса могут отличаться. Не используйте для этого GitHub Actions в приватном репозитории:
запуск каждые 5 минут выйдет за бесплатный лимит минут, а расписание там ещё и нестабильно (запуски задерживаются).

Проверка вручную:
```bash
curl -H "Authorization: Bearer $CRON_SECRET" https://ВАШ-ДОМЕН.vercel.app/api/cron/tick
```

## Вариант B. Тариф Pro: cron внутри Vercel

Замените `crons` в `vercel.json` на:
```json
"crons": [
  { "path": "/api/cron/tick", "schedule": "*/5 * * * *" },
  { "path": "/api/cron/cleanup", "schedule": "0 3 * * *" }
]
```
и отключите задачу во внешнем планировщике (иначе она будет выполняться параллельно; это безопасно — дубли исключены, но лишняя нагрузка).

## Важно про тариф

Тариф Hobby предназначен для некоммерческого использования. Для работающего салона предполагается Pro
(см. актуальные условия Vercel). Без частого cron бот остаётся рабочим, но напоминания и синхронизация с таблицей не выполняются.
